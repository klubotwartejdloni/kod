# Plan Klubu Otwartej Dłoni

1. Tu wpiszemy nowe zaplanowane prace.

2. Główna strona – animowana dłoń w lewym górnym rogu głównego PNG. Dłoń ma delikatnie machać, a znajdujący się w jej środku odcisk psiej łapy ma subtelnie przygasać i wracać. Animacja ma być osobnym, przezroczystym elementem nałożonym nad istniejące PNG, bez zmiany oryginalnego PNG. Zrobić w późniejszym terminie.

3. Domena klubotwartejdloni.pl – konfiguracja DNS dla GitHub Pages. W OVH są ustawione cztery rekordy A: 185.199.108.153, 185.199.109.153, 185.199.110.153 i 185.199.111.153. GitHub Pages nadal zgłasza „NotServedByPagesError”. Czekamy na propagację DNS. Po propagacji najpierw sprawdzić publiczny DNS, a dopiero gdy potwierdzi właściwe adresy GitHub Pages, kliknąć w GitHub Pages „Check again”. Nie zmieniać teraz rekordów DNS ani nie dodawać kolejnych bez konkretnej diagnozy.
